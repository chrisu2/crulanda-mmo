# Visual review, 2026-09-29

An independent reviewer checked every world-tour screenshot (`work\world-captures`, build of 2026-09-29 02:00), and a second reviewer re-checked each reported defect.
Result: 81 defects confirmed and 7 rejected. Screenshot names are `<zone>-<NN>-<shot>.png`, and positions are pixels in a 1440x900 frame.
Nothing below has been fixed yet. Some items are about how the capture tour frames a shot rather than about the game itself.
