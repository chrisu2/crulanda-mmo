# Crulanda Canon (STUB)

Status of every entry must be one of: CANON, CANON-EXPANDED, GAME-ONLY, PROVISIONAL (brief s.64).

The Crulanda novels/canon documents were **not available** while building Phase 0, so nothing here is extracted from
them. Phase 0 content deliberately uses neutral placeholder names (`actor.test_*`) and marks all definitions
`CanonStatus.Provisional` or `GameOnly`.

Treat as PROVISIONAL until the source documents are supplied and cross-checked.
